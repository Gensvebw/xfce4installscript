# xfce4installscript
This script made for installing xfce4 on termux desktop

To Download script just download raw files or just execute this:

For curl:

```
curl -sSL https://raw.githubusercontent.com/Gensvebw/xfce4installscript/main/installxfce4fortermux.sh | bash
```

For download script locally:

```
cd ~
wget https://raw.githubusercontent.com/Gensvebw/xfce4installscript/main/installxfce4fortermux.sh
chmod +x installxfce4fortermux.sh
sh installxfce4fortermux.sh
```

```
pkg install wget # If you didn't install wget
```
